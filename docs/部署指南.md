# 前端自动部署指南

## 部署流程

```
本地 push 代码到 GitHub（main 分支）
    ↓ 自动触发
GitHub Actions 执行 .github/workflows/deploy.yml
    ① 拉取代码 → ② 安装 Node.js → ③ npm ci 安装依赖
    ④ npm run build 构建 dist/ → ⑤ rsync 通过 SSH 上传到服务器
    ↓
线上 https://new-king.com 更新完成（约 1~2 分钟）
```

## 部署目标

| 项 | 值 |
|---|---|
| 服务器 | 111.231.13.51，SSH 端口 22，用户 root |
| 网站目录 | `/opt/1panel/www/sites/new-king.com/index/` |
| 部署方式 | SSH 密钥（`~/.ssh/newking_deploy`），无需密码 |

## 触发方式

1. **自动**：push 到 main 分支即触发
2. **手动**：GitHub 仓库 → Actions → 左侧「自动部署」→ Run workflow

## 配置依赖（已配置好，改动才需要动）

- `.github/workflows/deploy.yml`：流水线定义
- GitHub 仓库 Secrets（Settings → Secrets → Actions）：
  `DEPLOY_KEY`（SSH 私钥）、`SERVER_HOST`、`SERVER_PORT`、`SERVER_USER`、`SERVER_TARGET`

## 手动部署（不经过 Actions）

```bash
cd 项目目录
npm run build
rsync -avz --delete -e "ssh -i ~/.ssh/newking_deploy -p 22" \
  dist/ root@111.231.13.51:/opt/1panel/www/sites/new-king.com/index/
```

## 注意事项

- 部署目标必须是 `.../new-king.com/index/`（1Panel 网站根目录在域名目录的 index 子目录），写错会出现"部署成功但线上不变"
- `rsync --delete` 会自动删除服务器上的旧文件，无需手动清理
- push 偶发网络错误（HTTP2 framing layer）时用 `git -c http.version=HTTP/1.1 push origin main`
