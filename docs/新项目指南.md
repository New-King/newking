## 项目页数据模型（新增项目的固定流程）
用户提供 → Agent 实现。项目页数据已改为**从后端 `/api/content` 拉取**（`content/projects/*.md`），
不再用 `mockData.js` 的 projects 数组。每个项目的 md frontmatter 含：
`title / date / description / cover / url`，`cover` 是前端几何封面模板名（ring/square/triangle/dots/cross）。

- 悬停预览动画在 `src/pages/ProjectsPage.jsx` 的 `PREVIEW_BY_ID` 里按 id 映射（scene 模板：terminal/chat/form/list/canvas/transfer）。
- 预览是「示意动画」而非真实截图/视频：轻量、零素材、统一风格，访客想看详情自行点击进入。
- 用户若提供真实封面图，需先与用户确认后扩展 `cover` 支持图片。
- 列表顺序由后端按 frontmatter `date` **倒序**（新项目日期越新越靠前），与文件名 `j{N}` 前缀无关。

**新增项目 checklist（示例：j7-box-newking）**
1. 新建 `content/projects/j{N}-{slug}.md`（frontmatter + 正文）
2. 选定 `cover` 几何名（与现有项目不重复为佳）
3. 若无合适 scene：在 `src/components/projects/scenes/` 新建组件，并在 `scenes/index.js` 注册
4. 在 `ProjectsPage.jsx` 的 `PREVIEW_BY_ID` 增加短 id 映射（如 `j7`）
