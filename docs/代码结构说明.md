# 代码结构说明

技术栈：React 18 + Vite + Tailwind CSS v3 + react-router-dom v6，纯前端，无后端。
本文按「数据模型 → 文件逐个讲解 → 关键流程 → 命名约定」组织，适合快速接手。

## 1. 数据模型（地基）

### 消息 Message
```js
{ id: number, role: 'user' | 'assistant', text?: string, blocks?: Block[] }
```
- 用户消息：只有 `role: 'user'` 和 `text`，**没有 blocks**（很多地方要对此做空保护）。
- 助手消息：`role: 'assistant'` + `blocks: []`，回复内容全部是"块"。

### 内容块 Block
```js
{ id: number, type: 'thinking'|'tool'|'text'|'image'|'code'|'audio'|'video', status: 'loading'|'running'|'streaming'|'done'|'paused', ...payload }
```
- 一个块 = 一种内容类型的一个生命周期实例。
- `status` 驱动渲染：`loading/running/streaming` 显示骨架屏或进行中状态，`done` 显示内容，`paused` 显示已暂停。
- payload 按类型不同：`tool` 有 `name/result`，`text` 有 `content`，`image` 有 `src/caption`，`code` 有 `language/code`，`audio/video` 有 `title/duration`。

### 轮次 Turn
`AgentChat` 里 `turns` 由 `messages` 派生：**一条用户消息 + 其后的助手消息 = 一轮**。左侧定位条、摘要都基于轮次。

## 2. 文件逐个讲解

### 2.1 src/components/chat/AgentChat.jsx —— 核心（约 440 行）

**状态（渲染用）**
| 变量 | 含义 |
|---|---|
| `started` | 是否进入对话模式（初始态居中输入框 ↔ 对话态） |
| `messages` | 全部消息数组（唯一数据源） |
| `pending` | 正在生成的回复数（>0 时发送按钮变暂停、禁止连续发送） |
| `paused` | 是否手动暂停过（暂停后按钮恢复发送） |
| `input` | 输入框内容 |
| `atBottom` | 滚动是否在底部（控制"跳到底部"按钮显隐） |
| `navHidden` | 导航是否隐藏（来自 `nav-visibility` 事件，驱动预留条塌缩） |
| `nearTop` | 滚动是否在顶部附近（scrollTop < 55） |

**ref（异步闭包里读的"最新值"）**
| 变量 | 含义 |
|---|---|
| `formRef` | 输入表单 DOM（开场滑动动画的载体） |
| `inputElRef` | input DOM（发送后聚焦） |
| `scrollRef` | 消息滚动容器 DOM |
| `turnRefs` | 每轮消息的 DOM 节点数组（定位条跳转用） |
| `stuckRef` | 用户是否停留在底部附近（决定自动滚动跟不跟随） |
| `mountedRef` | 组件是否挂载（异步驱动中途卸载时安全退出） |
| `pendingRef` | `pending` 的同步镜像（异步 finally 里加减） |
| `pausedRef` | `paused` 的同步镜像（驱动每个步骤检查） |
| `pauseWakeRef` | "可打断 sleep"的唤醒函数（点暂停时立刻调用） |
| `pendingSlideRef` | 开场动画前输入框的旧位置（useLayoutEffect 里做位移动画） |
| `doneResolversRef` | 打字机完成回调的注册表：blockId → resolve |

**关键方法**
| 方法 | 作用 |
|---|---|
| `runSlide(el, fromTop)` | 开场动画：把元素从旧位置 transform 平滑滑到新位置（FLIP 思路）。监听 `transitionend` 清理，且**只认自身 transform 事件**（子元素冒泡的会提前打断动画） |
| `turns` (useMemo) | 消息按轮次分组 |
| `turnSummaries` (useMemo) | 每轮摘要（问题 + 回复片段），供定位条预览 |
| `scrollToBottom()` | 平滑滚到底部 |
| `handleScroll` | 滚动时更新 `stuckRef / atBottom / nearTop` |
| `jumpToTurn(i)` | 定位条点击后滚动到第 i 轮 |
| `onBlockDone(blockId)` | 打字机完成回调：按 id 找到 resolve 并唤醒驱动 |
| `handlePause()` | 暂停：置 pausedRef、唤醒当前 sleep、清理进行中的块（loading 移除、running→paused、文字冻结） |
| `handleSend(e)` | 发送：禁止生成中连续发送 → 派发 `nav-hide` → 记录滑位 → 追加用户消息 → 启动 `startReply` |
| `startReply(text)` | mock 回复驱动（见下方） |

**startReply 驱动 —— 最重要的一段**
- 追加一个空助手消息，然后按脚本依次"加块 → 等待 → 更新块"：
  `thinking(2s) → tool×3 → text(打字机) → image → code → audio → video`
- 三个内部工具：
  - `update(patch)`：更新本条助手消息整体
  - `updateBlock(blockId, patch)`：按 id 更新某个块（status 流转）
  - `addBlock(block)`：追加一个块
  - `sleepPauseable(ms)`：可被暂停打断的延时（点暂停时 `pauseWakeRef` 立即唤醒）
- 每个步骤后检查 `mountedRef`（卸载）和 `pausedRef`（暂停），任一为真就 `return`，`finally` 里递减 `pendingRef`。
- **流式文字特殊处理**：文字块进入 `streaming` 后，驱动 `await` 一个 Promise，由打字机组件完成后通过 `onBlockDone(blockId)` 唤醒——这是驱动能走到图片/代码/音视频的前提（之前 bug 就在这里）。

**导航联动（事件通信）**
- 派发：`nav-hide`（发送消息时）、`nav-autohide-on/off`（有/无对话）
- 监听：`nav-visibility`（导航隐藏/显示 → 更新 `navHidden`）

**布局**
- 消息区 `absolute bottom-20`：底部到输入区上方为止，**不把输入区算进聊天区域**。
- 顶部预留条：`height: navHidden && nearTop ? 0 : 20` —— 导航显示时垫在导航下保证首条消息完整可见；导航隐藏且停在顶部时塌缩，消息上移 20px 不留空白。
- 输入框：初始 `max-w-xl` 居中，进入对话后 `max-w-2xl` 与聊天列等宽（max-width 有过渡）。
- 发送按钮：生成中原地变暂停按钮（`pending > 0 && !paused`），`handleSend` 里也有守卫拦回车。

### 2.2 src/components/Navbar.jsx

**NAV 配置**：五项，带 `groups/contact/quote` 标记，渲染不同的 hover 面板。

**状态**：`open`（桌面哪个菜单项的面板展开）、`hidden`（导航是否隐藏）、`drawerOpen`（移动端抽屉）、`canAutoHide`（是否启用自动隐藏，按 `(hover: hover) and (pointer: fine)` 判断——触屏禁用，避免隐藏后唤不出）。

**自动隐藏机制**
- `show()`：鼠标交互（mousemove/mousedown/wheel/touchstart）→ 显示 + 重置 5 秒闲置计时；计时到且 `autoHideRef` 为真才隐藏。
- `autoHideRef`：由 `nav-autohide-on/off` 事件控制（有对话才能自动隐藏）。
- 监听 `nav-hide` 事件（发送消息）→ 立即隐藏。
- **不用 scroll 事件**做唤醒——聊天区自动滚动会误触。

**桌面端**（md+）：居中 5 项，hover 展开下拉面板（首页=站点文案 / 博客项目笔记=最新 3 条带日期分组 / 联系=电话邮箱）。

**移动端**（<md）：右上角汉堡按钮，点开下拉抽屉面板（5 项纯链接），点项跳转并关闭；触屏下不自动隐藏。

**事件**：派发 `nav-visibility`（hidden 变化时通知聊天页）。

### 2.3 src/components/chat/TurnRail.jsx —— 左侧定位条

- 每条横杠 = 一轮。常态等长浅灰；悬停时焦点条变黑最长、向两侧按 `lenFor`（指数衰减）递减成钟形。
- **矩形悬停区设计**：外层透明矩形统一处理鼠标（`onMouseLeave` 清空、`onMouseMove` 按 Y 坐标映射焦点），焦点条与预览面板跟随鼠标；只有进入窄条区（`onMouseEnter`）才激活，未激活时鼠标掠过不触发。
- `indexAt(rawY)`：Y 坐标 → 最近条索引（最近邻映射）。
- 预览面板：显示该轮的问题 + 回复摘要 + 「跳转至此轮」按钮。
- 点击条区任意位置 → `onSelect(hover)` 跳转。

### 2.4 src/components/chat/blocks.jsx —— 内容块渲染

每个块类型一个组件，自带 loading 骨架和 done/paused 形态：
- `ThinkingBlock`：仅「正在思考」+ 扫光动画（`.think-sweep`，见 index.css），done 后淡出。
- `ToolCallCard`：running（转圈）→ paused（暂停图标）→ done（勾 + 结果）。
- `TextBlock`：loading 骨架 → streaming（Typewriter，可被 paused 冻结）→ done 静态文本。
- `ImageBlock / AudioCard / VideoCard`：loading 骨架 → 内容（音频带波形动画，视频带播放占位）。
- `BlockRenderer`：按 `block.type` 分发的唯一出口。

## 3. 关键流程时序

### 发送一条消息
1. `handleSend`：校验 → 拦截生成中连续发送 → 派发 `nav-hide`（导航隐藏）→ 记录表单旧位置 → 追加用户消息 → `setStarted(true)` → `startReply`。
2. `useLayoutEffect`：`runSlide` 把输入框从居中滑到底部（0.7s 快动缓停）。
3. `startReply` 驱动依次产出 thinking → tools → text → image → code → audio → video，每步 `updateBlock` 驱动骨架屏 → 内容流转。
4. 文字块靠 Typewriter 完成后 `onBlockDone` 唤醒驱动继续。
5. `finally` 递减 `pending` → 发送按钮恢复。

### 点击暂停
`handlePause`：置 `pausedRef` → `pauseWakeRef` 唤醒当前 sleep/打字机等待 → 驱动在下一个检查点退出 → 清理进行中块（loading 移除、running→paused）→ 文字冻结。`pending` 归零后按钮恢复发送，可发新消息。

### 导航自动隐藏
- 无对话：`nav-autohide-off` → 导航常显。
- 有对话：发送消息 `nav-hide` 立即隐藏；之后鼠标 5 秒不动再隐藏；任何鼠标交互立即显示。
- 隐藏/显示变化派发 `nav-visibility` → 聊天页更新 `navHidden` → 顶部预留条塌缩/恢复（配合 `nearTop`）。

### 左侧定位条
- 消息 ≥2 轮出现；hover 矩形区 → 焦点条 + 预览面板跟随鼠标；点击 → `jumpToTurn` 滚动定位。

## 4. 命名约定（读代码的钥匙）

- **xxx / xxxRef 成对**：`pending`/`pendingRef`、`paused`/`pausedRef` —— state 用于渲染，ref 用于异步闭包/事件回调里读"最新值"（避免闭包捕获过期值）。这是本项目最重要的模式。
- **id 生成**：模块级 `let uid = 0; nextId()` 全局自增，保证消息/块 id 唯一。
- **doneResolversRef 模式**：异步流程需要"等一个 UI 事件"时，把 resolve 存进 `{ id: resolve }` 注册表，UI 完成回调按 id 取出来调用。
- **状态字符串**：块状态统一用 `loading / running / streaming / done / paused`，组件按状态渲染。

## 6. 其他约定

- **统一缓动**：`tailwind.config.js` 把 `transitionTimingFunction.DEFAULT` 设为 `cubic-bezier(0.22, 0.61, 0.36, 1)`（快动缓停），所有 `transition-*` 默认生效；行内动画（开场滑动）用同一曲线字面量。
- **自定义动画**：`fade-in-up`（消息入场）、`blink`（打字机光标）、`eq`（音频波形）、`dot`（等待点）；`think-sweep` 在 index.css 里（正在思考的扫光）。
- **移动端**：`md:` 断点切换桌面菜单/移动端抽屉；触屏（`(hover: hover) and (pointer: fine)` 不匹配）禁用导航自动隐藏。
