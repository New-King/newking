# 设计规范 —— 深灰极简 · Apple 质感

> 本项目唯一的 UI 风格，全站所有页面与组件必须遵循本规范。
> 风格来源：skill 库 Bento Grids（Apple-style），强调色由蓝色改为**深灰**（无彩色）。
> 设计令牌以 `tailwind.config.js` 为唯一来源，本文件是对它的说明与使用约定。

---

## 1. 风格定位

- **底色**：暖白 `#F5F5F7`，大量留白。
- **文字**：墨黑 `#1D1D1F` 四级灰阶。
- **强调色**：**深灰** `#171717`（非彩色）。禁止使用蓝/紫/绿等彩色强调。
- **质感**：白卡片 + 柔和阴影 + 大圆角（16px）+ 发丝细边框，干净、高级、克制。
- **氛围词**：Apple 官网 / Linear / 极简 / 有质感。

---

## 2. 设计令牌（tailwind.config.js）

### 颜色

| 令牌 | 值 | 用途 |
|---|---|---|
| `page` | `#F5F5F7` | 页面底色 |
| `card` | `#FFFFFF` | 卡片 / 输入框 / 下拉面板 |
| `ink` | `#1D1D1F` | 主文字 / 深色元素（代码块底色） |
| `ink-soft` | `#3A3A3C` | 次级文字 |
| `ink-muted` | `#6E6E73` | 弱文字 |
| `ink-faint` | `#86868B` | 更弱文字 / 占位符 |
| `accent` | `#171717` | 强调深灰：按钮底、用户气泡、选中下划线、完成勾、焦点条 |
| `accent-hover` | `#404040` | 强调元素 hover 色 |

### 阴影

| 令牌 | 值 | 用途 |
|---|---|---|
| `shadow-apple` | `0 4px 16px rgba(0,0,0,0.06), 0 1px 3px rgba(0,0,0,0.04)` | 卡片、气泡 |
| `shadow-apple-lg` | `0 12px 32px rgba(0,0,0,0.1)` | 浮层（导航下拉、定位条预览） |
| `shadow-apple-input` | `0 1px 2px rgba(0,0,0,0.04)` | 输入框 |

### 圆角

- 卡片 / 气泡 / 面板：`rounded-2xl`（11px，全局令牌统一收小）
- 输入框 / 发送按钮：`rounded-full`（胶囊）
- 代码块：`rounded-2xl`

### 字体

- `font-sans`：Inter → Noto Sans SC → PingFang SC → system-ui（中文用黑体系，不用衬线）
- `font-mono`：ui-monospace / SFMono / Menlo

### 动效

- 全局缓动 `cubic-bezier(0.22, 0.61, 0.36, 1)`（快动缓停）
- hover 过渡 `duration-200`；按钮按压 `active:scale-95`
- 消息入场 `animate-fade-in-up`；尊重 `prefers-reduced-motion`

## 3. 组件规范（已落地，新增组件照此样式）

| 组件 | 样式要点 |
|---|---|
| 顶部导航 | 毛玻璃：`bg-white/80 backdrop-blur-xl` + 发丝边框 `border-black/[0.08]`；链接 `ink-muted`/hover `ink`；选中下划线 `bg-accent` |
| 导航下拉面板 | `bg-card` + `border-black/[0.06]` + `shadow-apple-lg` + `rounded-2xl` |
| 移动端抽屉 | 实心白 `bg-white`（省 GPU，无毛玻璃） |
| 输入框 | `bg-card` + 胶囊 `rounded-full` + `border-black/[0.08]` + `shadow-apple-input`；聚焦**不变色**，仅阴影微升 `focus:shadow-apple`（无边框变色、无光环） |
| 发送 / 暂停 / 播放按钮 | `bg-accent text-white` + `hover:bg-accent-hover` + `active:scale-95`（圆形） |
| 用户气泡 | `bg-accent text-white` + `rounded-2xl rounded-br-sm` + `shadow-apple` |
| AI 气泡 | `bg-card text-ink` + `rounded-2xl rounded-tl-sm` + `shadow-apple` |
| 工具调用卡 | 单行扁卡片：`bg-card` + `rounded-2xl` + `shadow-apple` + `py-2`；左侧 20px 圆形图标底（进行中/暂停浅灰、**完成淡绿** `bg-green-100` + 深绿对勾 `text-green-600`），右侧 12px 弱灰单行文字 |
| 音频卡 / 视频卡 / 图片 | `bg-card` + `rounded-2xl` + `shadow-apple`（骨架屏用 `bg-neutral-100` 或 `bg-card`+脉动） |
| 代码块 | 深色 `bg-[#1D1D1F]` + `rounded-2xl` + `shadow-apple`，头部发丝分隔 |
| 左侧定位条 | 焦点条 `bg-accent`，常态 `bg-[#D2D2D7]`；预览面板同下拉面板样式 |
| 占位页（PageShell） | eyebrow `text-ink-faint` 大写字距；标题 `text-ink`；说明 `text-ink-muted` |
| 联系页卡片 | `bg-card` + `border-black/[0.06]` + `shadow-apple`，hover `scale-[1.02]` + `shadow-apple-lg` |

## 4. 硬性规则

1. **无彩色**：强调一律用 `accent`（深灰 #171717）。任何新 UI 禁止引入蓝 / 紫 / 绿等彩色作为强调。
2. **文案不可擅自改动**：用户可见文字（占位符、按钮、页面文案、导航）一律不得增删改；确需改动先问用户。
3. **不新造色值**：所有颜色必须来自上面的令牌；特殊场景需先与用户确认后再加入 `tailwind.config.js` 并同步更新本文档。
4. **阴影与圆角统一**：卡片用 `shadow-apple` 系、圆角 `rounded-2xl`（16px）；不要随意换边框/阴影风格。
5. **交互反馈**：可点击元素 hover 过渡 200ms；按钮按压缩放。

---

## 4.1 深色模式（Dark Mode）

- 已内置深色模式：`<html class="dark">` 切换（Tailwind `darkMode: 'class'`），用户选择存 `localStorage('theme')`。
- **令牌全部为 CSS 变量**（`index.css`：`:root` 浅色 / `.dark` 深色），组件一律用令牌类名，**禁止硬编码色值**（硬编码的不会跟随主题）。
- **新增组件必须提供 `dark:` 变体**：`dark:bg-white/10`、`dark:border-white/10`、`dark:text-ink-*` 等。
- **禁止使用不跟随主题的 Tailwind 中性色**（`bg-neutral-*`、`text-neutral-*`、`border-black/*`、`bg-white`）——深色下不会自动适配；确需使用必须配 `dark:` 变体。
- **网格背景**（BgGrid）：颜色用 CSS 变量（`--grid-line/--grid-line-hot/--grid-dot/--grid-dot-hot`），深色下"线变深"效果自动反向为"变亮"。
- **代码块**在深浅模式下都保持深色（设计意图）；"正在思考"扫光在深色下用深色光柱（`.dark .think-sweep::after`）。
- 深色强调色为比底亮的灰（`--accent: 58 58 60`），按钮/用户气泡文字保持白色。

---

## 5. 新增页面 / 组件如何套用

1. 打开本文档 + `tailwind.config.js`，使用现有令牌（`bg-page`、`text-ink`、`bg-card`、`shadow-apple`、`text-accent` 等）。
2. 参照 §3 现有组件样式，不要另起炉灶。
3. 完成 UI 后截图自查，或询问用户确认。
