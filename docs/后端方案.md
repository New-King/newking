# 后端架构方案（Agent · 知识库 · 网关）

> 状态：方案定稿，待实施。流程：本地先跑通 → 再部署线上。
> 与前端 `docs/代码结构说明.md`、部署 `docs/部署指南.md` 配套。

## 0. 目标

- 主页对话 =「我的数字分身」：回答关于本人 + 网站全部内容（博客/项目/笔记）的问题。
- 命中知识库时附带图片 / 链接 / 视频等富媒体块。
- 采用行业标准成熟闭环，可整体复现到其他项目（公司网站 + Agent、大数据量场景）。
- 内容源 = Git 仓库中的 markdown（`content/`），git 即唯一内容源；**暂不做 CMS / 管理后台**（单人作者，md + git + GitHub 手机端可满足灵活增改）。

## 1. 总体架构

```
Git 仓库
  content/*.md（内容源：博客/笔记/项目/about/contact，frontmatter 带媒体元数据）
        │ push → GitHub Actions：构建前端 + 同步 content → 服务器 + 触发索引接口
        ▼
知识库索引管线（Python，接口触发 / 可独立运行）
  解析 → 按标题切块 → embedding → upsert pgvector（增量、幂等、按 hash 判变）
        ▼
PostgreSQL + pgvector（唯一数据源：文档向量 + 元数据）
  测试库 newking_test / 正式库 newking_prod（同一实例，靠连接串切换）
        ▼
Agent 服务（Python FastAPI + LangGraph）
  混合检索(向量 + BM25) → BGE-reranker 精排 → prompt → DeepSeek 流式 → SSE 块事件
        ▼
Go 网关（对外唯一入口）
  静态托管 dist / SSE 透传 / 内容 API（读 content/ 供页面展示）
        ▼
前端 React（对话 + 四个页面，运行时从 API 拉数据）
```

质量闭环（后期）：LangSmith 全链路追踪 + RAGAS 评测（CI）。
部署：Docker Compose（Postgres + Python + Go）一键起。

## 3. 分步实施计划

### Step 1 · 内容层 `content/`
- 将 mockData 的博客 / 笔记 / 项目转为 md，frontmatter 约定（`title / date / description / cover / video / links`）。
- 补 `about.md` / `contact.md` / `resume.md`（需用户填真实信息）。
- 验收：解析脚本能读通全部 md。

### Step 2 · 服务器 PostgreSQL + pgvector（测试库先行）
- 在服务器（111.231.13.51）安装 Postgres + pgvector，建 `newking_test` 测试库。
- Postgres 只监听 `127.0.0.1`，本地开发经 **SSH 隧道**连接，不对外网暴露端口。
- 上线时在同一实例建 `newking_prod` 正式库，靠连接串切换。
- 验收：本地经 SSH 隧道 psql 能连接，`CREATE EXTENSION vector` 成功。

### Step 3 · 知识库索引管线（★ 此时定 embedding）
- FastAPI 提供 `POST /api/index/index`：扫 `content/` → 按标题切块 → embedding → upsert pgvector。
- 增量幂等：按内容 hash 只处理变更，删除已消失文档。
- 验收：重复跑不重复插，库内存在向量。

### Step 4 · Agent 服务
- `POST /agent/stream`（SSE）：历史消息 → 混合检索 → rerank → prompt → DeepSeek 流式 → 块事件。
- 定义 SSE block 协议（对齐前端 `thinking / tool / text / image / link / video`）。
- 验收：curl 收到完整事件流。

### Step 5 · Go 网关
- 静态托管、`/agent` SSE 透传、内容 API（读 `content/`）。
- 验收：浏览器经 Go 访问站点并可对话。

### Step 6 · 前端接入
- `startReply` mock 换 SSE 客户端；四个页面从 API 拉数据；新增 `link` 块渲染。
- 验收：首页真问答 + 页面真实数据。

### Step 7 · 部署与 CI/CD
- 服务器 Docker Compose（Postgres + Python + Go），Nginx 反代 `/api` → Go。
- 扩展现有 deploy.yml：构建前端 + Go → rsync `dist` + `content` → curl 触发索引（事件触发更新）。
- 验收：push 新博客 2 分钟内线上可答。

### Step 8 · 观测与评测
- LangSmith 追踪、RAGAS 评测（golden Q&A，改内容后 CI 跑）。
- 验收：评测分数可见、排障靠追踪。

## 4. 环境与配置

- **数据库**：直接部署在线上服务器；`newking_test` 测试库先行，上线时建 `newking_prod`。本地经 SSH 隧道访问，Postgres 不对外暴露。
- **本地**：本机直接跑 uvicorn / go / Vite；`.env` 存 DeepSeek key。
- **线上**：Docker Compose 全容器；key 由 GitHub Secrets → 服务器环境变量。
- **测试 / 正式**：同一 Postgres 实例两个库，`DATABASE_URL` 切换库名即可，代码不改。
- **知识库更新**：事件触发（push → CI → 索引接口）；定时增量扫描缓做。
