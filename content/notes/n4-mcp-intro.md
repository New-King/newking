## MCP 是什么

Model Context Protocol，一种让模型与外部工具、数据源连接的标准协议。

## 能做什么

通过 MCP，Agent 可以统一调用搜索、知识库、数据库等资源，而不必为每个工具定制集成方式。

## 入门路线

从官方的 Hello World 开始，理解 server 与 client 的交互，再逐步接入自己的数据源。
