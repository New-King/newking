## 技术选型

React + Vite + Tailwind，纯前端起步。选择这套组合看重的是生态成熟与上手成本低。

## 设计取舍

以「对话」为入口，而不是传统的列表式首页。导航承载内容结构，首页用一次对话演示 Agent 的能力。

## 踩坑记录

- 深色模式：所有颜色走设计令牌，避免主题切换时出现死板的中性色
- 动画：隐藏元素不要用 opacity 占位，会导致容器高度异常
- 部署：rsync 目标路径必须写到网站根目录的 index 子目录
